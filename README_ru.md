Filler заполняет свободное место накопителя временными файлами и затем снова удаляет их. Вы выбираете встроенную память или карту памяти либо папку на них; Filler показывает измеренное свободное место и часть, которую оставляет свободной для системы, записывает не больше подтверждённого вами объёма, показывая, сколько записано, процент и оставшееся время, и удаляет каждый записанный им файл - после завершённого запуска, остановки, ошибки записи, перезапуска или извлечения карты памяти. Ваши собственные файлы остаются как есть. На телефоне заполнение выполняется и по расписанию: в заданное время при закрытом приложении, даже после перезапуска, с обычным запасом 1 ГБ, не чаще раза в день, а каждый запуск виден в истории. Один идентификатор приложения, `com.sza.filler`, объединяет приложение для Android и приложение для Wear OS.

Это заполнение локального накопителя (Filler) из FastMediaSorter в виде отдельного приложения и самостоятельный продукт: у него нет общего кода приложения с другими продуктами семейства, только опубликованные контракты.

## Сборка

При установленных JDK и Android SDK команда `./gradlew :phone:assembleDebug :wear:assembleDebug` собирает отладочные APK приложения для телефона и приложения для часов. Откуда взялся продукт: [docs/PLAN_BOOTSTRAP_HANDOFF.md](docs/PLAN_BOOTSTRAP_HANDOFF.md).

## Конфиденциальность

Разработчик не получает никаких ваших данных: ни учётной записи, ни аналитики, ни рекламы, ни отслеживания. Filler не имеет доступа в интернет, поэтому ничто не покидает устройство; приложение для телефона запрашивает только то, что нужно, чтобы заполнение по расписанию запускалось вовремя при закрытом приложении, а приложение для часов - только то, что нужно, чтобы заполнение продолжалось при погасшем экране. Полный текст: [политика конфиденциальности](https://serzhyale.github.io/Filler_Android/privacy-ru.html).

## Установка APK из GitHub Releases или SourceForge

Подписанные APK для телефона и часов, опубликованные вне Google Play, приводят к тому, что Android просит разрешить неизвестные приложения из одного источника и может показать уведомление Play Protect о разработчике. Что означает каждый запрос, почему он появляется и что именно нажать, описано в [инструкции по установке](docs/INSTALL_TRUST-ru.md). То же приложение в Google Play подписано через Play App Signing и ни одного из этих запросов не вызывает.
