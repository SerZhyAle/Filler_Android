# Contract pointers

One pointer per shared contract this product produces, consumes or adopts: id, version, home, role, and what
this repository owes to stay conformant. The contract text lives only in the shared contracts catalog, which
`CLAUDE.md` locates; nothing here restates it. Cite a contract by id and section, never by link or path.
Versions were read from the catalog registry on 2026-11-10 (S0002) - re-read the registry, not this table,
before work at a boundary.

**Contracts owned here: none.** The product writes and reads no format another product reads. If a behaviour
must be shared with another product, it is written in the catalog first and a pointer appears here.
